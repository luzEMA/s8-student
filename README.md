Nombre del archivo: novaretail_comportamiento_clientes_2024.csv

Descripción: Contiene registros detallados sobre métricas de navegación, transacciones, variables demográficas y comportamiento de compra de los clientes de NovaRetail+.

🛠️ Tecnologías y Librerías
El análisis se desarrolló utilizando un stack estándar de Python para Ciencia de Datos:

Lenguaje: Python

Entorno: Google Colab / Jupyter Notebooks

Manipulación y Análisis: Pandas, NumPy

Estadística: SciPy

Visualización: Matplotlib, Seaborn
Clona este repositorio: git clone [https://github.com/luzEMA/s8-estudiante.git](https://github.com/luzEMA/s8-estudiante.git)
Navega hasta la carpeta del proyecto: cd s8-estudiante
Metodología y Análisis
Limpieza y Preparación: Tratamiento de valores nulos (NULLIF, COALESCE y técnicas equivalentes en Python), estandarización de formatos y filtrado de anomalías.

Análisis Exploratorio (EDA): Evaluación de distribuciones, detección de asimetrías y estudio de perfiles de consumo cero.

Correlación y Estadística: Generación de matrices de correlación, mapas de calor y evaluación de asociaciones bivariadas para determinar los drivers de comportamiento más influyentes.
